## The idea

This isn't meant to be the one definitive way to learn AI.

It's **one possible path** — a progression from programming fundamentals, through machine learning and deep learning, into the modern AI landscape.

Learn the concepts.

Build things.

Then follow wherever your curiosity takes you.
